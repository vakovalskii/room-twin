# Room Twin — цифровой двойник комнаты

```
телефон: capture.html (камера + гироскоп, подсказки «куда повернуться»)
   │  каждый кадр сразу на компьютер
   ▼
serve_capture.py + live.py: глубина, брак, живой план  →  телефон видит план и красные сектора
   │  «Готово»
   ▼
cloud.py: выравнивание кадров, облако, прямоугольник комнаты, plan_room.png, poses.json
   │
   ▼
агент (ты): смотришь план и кадры, пишешь room.json  →  render_html.py  →  room.html
```

Сборку комнаты делает агент, а не удалённая модель: скрипты дают геометрию (размеры, стены,
следы мебели на плане), ты по кадрам понимаешь, что где стоит.

## Предпосылки
1. Python 3.10+ и `uv` (или `pip install -r requirements.txt`).
2. Модель глубины `models/da2-metric-indoor-small.onnx` (99 МБ). Нет — один раз сконвертировать:
   ```bash
   uv run --python 3.12 --with torch --with transformers --with onnx --with onnxruntime \
     python tools/export_depth.py models/da2-metric-indoor-small.onnx
   ```

## Шаг 1. Съёмка (живая)
```bash
uv run --with numpy --with onnxruntime --with pillow python scripts/serve_capture.py
# печатает https://<ip>:8443/capture.html — открыть на телефоне в той же Wi-Fi
```
На iPhone: принять самоподписанный сертификат, разрешить камеру и «Движение и ориентация».
Страница ведёт человека сама: три круга (прямо / вниз / вверх), стрелка «поворачивайся вправо»,
шкала наклона, кадр снимается, когда телефон замер. Сектор жёлтый — компьютер считает, зелёный —
принят, красный — брак (смазано, не совпал со стенами соседей: человек, стол вплотную), туда надо
вернуться. В углу — план с компьютера и прикидка размера. «Темновато» → кнопка фонарика.

По «Готово» скан пишется в `captures/room-capture-<id>.json`, сервер сам запускает `cloud.py`
в `out/<id>/`. Без сервера страница отдаёт файл через «Поделиться» — тогда запусти `cloud.py` руками.

## Шаг 2. Облако
```bash
uv run --with numpy --with onnxruntime --with pillow \
  python scripts/cloud.py captures/room-capture-<id>.json --out out/<id> [--drop 3,11]
python scripts/sheet.py out/<id>
```
Получится в `out/<id>/`:
- `plan_room.png` — план в координатах комнаты: начало в углу SW, x вдоль стены S, y вдоль W,
  сетка 0.5 м, серое — стены, цветное — всё ниже 1.2 м (следы мебели), лучи — кадры с номерами;
- `sheet.jpg` — все кадры с номером, курсом в комнате (0° = стена N, 90° = E) и браком;
- `poses.json` — `room.width/depth`, `fit_error_m`, `camera_xy`, по кадрам `yaw_room`, `pitch`;
- `cloud.html` (3D-облако, срез по высоте), `cloud.ply` (для MeshLab/Blender), `frames/`, `depth/`.

Кадры, не совпавшие со стенами соседей, выкидываются сами. Посмотри `sheet.jpg`: если в кадре
человек или мусор, а он прошёл, перезапусти с `--drop <номера>` (глубина закеширована, это ~25 с).
`fit_error_m` > 0.3 — скан шумный, предложи переснять.

## Шаг 3. Сборка комнаты — делаешь ты
1. Открой `plan_room.png` и `sheet.jpg` (Read).
2. По кадрам назови предметы и проёмы; по `yaw_room` кадра пойми, у какой стены каждый;
   по цветным пятнам на плане сними `x, y` (центр) и `w, d` (габарит). Высоту бери типовую
   (кровать 0.5, стол 0.75, шкаф 2.0) или по кадру относительно известного (дверь 2.0–2.1 м).
3. Напиши `out/<id>/room.json` по образцу `samples/room.sample.json`:
   `size {width, depth, height}` из `poses.json`; `objects[]` — `id, category, name, color, material,
   mount (floor|wall|ceiling), x, y, w, d, h, elevation, wall`; `openings[]` — `door|window`,
   `wall`, `x` или `y` вдоль стены, `w, h, elevation`. Стены: S при y=0, N при y=depth, W при x=0, E при x=width.
   Категории — список `CATEGORIES` в `scripts/build_room.py` (bed, desk, chair, wardrobe, shelf,
   curtain, picture…). Отдельные модели во вьюере есть у sofa, sofa_corner, table, coffee_table,
   desk, kitchen_island, tv, rug, plant, lamp_pendant, column; остальное рисуется коробкой по габариту.
4. `python scripts/render_html.py out/<id>/room.json` → `room.html`. Сделай скриншот, сверь с
   кадрами, поправь json, пересобери.

## Что отдать пользователю
`room.html` (3D: перспектива/сверху, подписи стен и проёмов, «Свет»), `cloud.html`, размер
комнаты и разброс стен, список предметов — пусть поправит, что видит иначе.

## Запасной путь: разметка vision-моделью
`scripts/build_room.py` — старый автоматический сборщик через NeuralDeep Hub (`NEURALDEEP_API_KEY`,
~20 с на кадр, путает тёмную мебель). Брать, только если пользователь просит без участия агента.

## Границы
- Точность — десятки сантиметров: глубина с одной камеры, не LiDAR (Safari его не отдаёт).
- Комната сводится к прямоугольнику. Скан с одной точки: за шкафом не видно.
- Высота телефона над полом определяется по облаку; потолок по умолчанию 2.7 м, лучше ввести на странице.
