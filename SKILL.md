# Room Twin — цифровой двойник дома

```
агент: сервер + главная страница на компьютере
   │  человек открывает адрес/QR на телефоне — страница показывает «телефон подключён»
   ▼
телефон: capture.html — стрелки «куда повернуться», 3 круга, мини-план с компьютера
   │  каждый кадр сразу на компьютер: глубина, брак, живое облако на странице «Статус»
   ▼
«Готово» → cloud.py: выравнивание кадров, облако, прямоугольник комнаты (агент следит watch.py)
   │
   ▼
агент: план + карта высот + кадры → room.json → room.html
   │
   ▼
человек: «Комнаты» → «Редактор» — двигает, крутит, меняет размеры, отмечает электрику, сохраняет
```

## Предпосылки
1. Python 3.10+ и `uv` (или `pip install -r requirements.txt`).
2. Модель глубины `models/da2-metric-indoor-small.onnx` (99 МБ). Нет — один раз сконвертировать:
   ```bash
   uv run --python 3.12 --with torch --with transformers --with onnx --with onnxruntime \
     python tools/export_depth.py models/da2-metric-indoor-small.onnx
   ```

## Флоу агента

### 1. Запусти сервер и открой главную
```bash
uv run --with numpy --with onnxruntime --with pillow python scripts/serve_capture.py   # в фоне
open https://localhost:8443/        # macOS; страница с меню «Статус · Комнаты · Телефон»
```
Сервер печатает адрес для телефона (`https://<ip>:8443/capture.html`); он же и QR — на вкладке
«Телефон». Скажи пользователю: та же Wi-Fi, сертификат самоподписанный («Подробнее» → «Перейти»),
разрешить камеру и «Движение и ориентация», стоять в центре комнаты (не сидеть), три круга.

### 2. Следи за съёмкой
```bash
python scripts/watch.py            # в фоне; события по строке, выход при готовом облаке
```
Пересказывай пользователю важное: телефон подключился, сколько кадров принято, брак и почему
(«не совпал с соседями» — человек или предмет вплотную, «смазано»). Последняя строка
`ГОТОВО out/<id>` (код 0) — облако собрано. Код 1 — смотри `out/<id>/build.log`.
Пока идёт съёмка, на «Статусе» у пользователя растёт 3D-облако и план — ему ничего не надо делать.

### 3. Собери комнату — делаешь ты, не удалённая модель
```bash
python scripts/sheet.py out/<id>            # sheet.jpg — кадры с номером, стеной, наклоном, браком
python scripts/heightmap.py out/<id>        # height.png — карта высот: кровать, столы, шкафы
```
Посмотри (Read) `plan_room.png`, `height.png`, `sheet.jpg`, `poses.json`:
- `poses.json → room.width/depth/fit_error_m/camera_xy`, у кадров `yaw_room` (0° = стена N, 90° = E);
- на кадрах назови предметы и проёмы, по `yaw_room` пойми стену, по пятнам на карте высот сними
  центр `x, y` и габарит `w` (вдоль стены) × `d` (от стены); высоту — по карте или типовую.
- человек или мусор в кадре, а он не забракован — `cloud.py ... --drop <номера>` (глубина в кеше).

Напиши `out/<id>/room.json` по образцу `out/*/room.json` или `samples/room.sample.json`:
`size {width, depth, height}`; `objects[]`: `id, category, name, color, material, mount
(floor|wall|ceiling), x, y, w, d, h, elevation, wall, electric, power_w`; `openings[]`: `type
(door|window|arch), wall, x, y` (точка на линии стены), `w, h, elevation`. Стены: S при y=0,
N при y=depth, W при x=0, E при x=width; `wall` у предмета — к какой стене он спиной.
Модели вьюера: bed, sofa, sofa_corner, desk, table, coffee_table, office_chair, chair, shelf,
wardrobe, bookcase, tv, monitor, picture, curtain, mirror, rug, plant, lamp_pendant, lamp_floor,
lamp_table, outlet, switch, ac_unit, radiator, fridge, washing_machine, pc, router, speaker, heater,
column; остальное — коробка по габариту.

```bash
python scripts/render_html.py out/<id>/room.json     # → room.html
```
Сделай скриншот, сверь с кадрами, поправь. Скажи пользователю: «Комнаты» → «Редактор».

### 4. Редактор (делает человек, агент подсказывает)
Открывается во вкладке «Комнаты» на главной (`out/<id>/room.html`, данные вшиты).
- клик — выбрать предмет, проём или стену; панель «Свойства» — все поля, включая ⚡ и мощность;
- указатели на выбранном: `1` двигать по полу, `2` высота, `3` крутить (шаг 15°), `4` размер;
  `R` +45°, `⇧R` +15°, стрелки — сдвиг 5 см, `Delete`, `Esc`, `M` — магнит к стенам;
- стена: клик → стрелка, тянешь — комната меняет размер, зелёный призрак показывает, куда встанет;
  предметы и проёмы у этой стены едут с ней;
- «Добавить»: двери/окна/арки, мебель, электрика (розетки, выключатели, свет, ТВ, ПК, кондиционер,
  холодильник, стиральная машина…), декор; сумма мощности — в панели вида;
- «Комната»: размеры, цвет стен, пол (паркет, тёмный дуб, плитка, ковролин, бетон),
  «Выровнять всё по полу и стенам»;
- `⌘S` / «Сохранить» — пишет `room.json` и пересобирает `room.html` на сервере; без сервера — скачать.
Правки человека — источник правды: перед своей правкой room.json перечитай его.

## Файлы скана `out/<id>/`
`frames/`, `depth/` (кеш глубины), `meta.json`, `cloud.ply` (MeshLab/Blender), `cloud.html`,
`plan.png`, `plan_room.png`, `height.png`, `sheet.jpg`, `poses.json`, `build.log`,
`room.json` + `room.html` (после шага 3). Исходник скана — `captures/room-capture-<id>.json`.

## Тесты без телефона
`ROOM_TWIN_HTTP=1 ... serve_capture.py 8444` — сервер без TLS для браузерных автотестов;
скан можно «проиграть» в него, отправляя кадры из готового `captures/*.json` в `/live/...`.

## Запасной путь: разметка vision-моделью
`scripts/build_room.py` — старый автосборщик через NeuralDeep Hub (`NEURALDEEP_API_KEY`,
~20 с на кадр, путает тёмную мебель). Только если пользователь просит без участия агента.

## Границы
- Точность — 10–20 см: глубина с одной камеры, не LiDAR (Safari его не отдаёт).
- Комната — прямоугольник; скан из одной точки, за шкафом не видно.
- Пока одна комната на скан; дом из нескольких комнат — следующий этап (общий план, общие стены).
